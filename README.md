# Cal-TF-2000

โปรแกรมคำนวณปริมาตรและระดับของ Tank Farm TF2000-01 พร้อมหน้าต่าง Windows

## เปิดใช้งานบน Windows

ใช้ Python 3.10 ขึ้นไปที่ติดตั้ง Tkinter (ตัวติดตั้ง Python สำหรับ Windows มีให้) ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

ดับเบิลคลิก `Start-TF2000.pyw` หรือเปิดจากโฟลเดอร์โปรเจกต์:

```powershell
python -X utf8 tank_gui.py
```

1. กรอกยอดเริ่มต้น, Load out และ Load in ของ DD-1 ถึง DD-4 เป็น bbl
2. ใส่ 0 สำหรับรายการที่ไม่มี ทุกช่องต้องเป็นตัวเลขที่มีค่าจำกัดตั้งแต่ 0 ขึ้นไป
3. กด **คำนวณ / Calculate** หรือ Enter เพื่อดูยอดสะสมและระดับแต่ละขั้นตอน
4. กด **ล้างค่า / Clear** เพื่อเริ่มใหม่ การแก้ข้อมูลจะล้างผลลัพธ์เก่าอัตโนมัติ

ระบบไม่บันทึกข้อมูลที่กรอกและไม่เชื่อมต่อเครือข่าย

## พฤติกรรมที่คงจากระบบเดิม

- **Load out นำไปบวก** กับยอดเริ่มต้นตามกระบวนการใช้งานของระบบนี้
- เพิ่ม Load in ของ DD-1, DD-2, DD-3 และ DD-4 ตามลำดับ
- แสดงระดับด้วยสูตรคาลิเบรตเดิม: `volume / 4.1404 - 491` หน่วย cm
- หน้าต่างแสดงครบทุกขั้นตอน รวมรายการที่เป็น 0 เพื่ออ่านยอดสะสมต่อเนื่อง

ตัวอย่าง: ยอดเริ่มต้น 1,000, Load out 100 และ DD-1 ถึง DD-4 เท่ากับ 10, 20, 30, 40 จะได้ยอดสุดท้าย 1,200 bbl

ค่าคาลิเบรตเป็นของ TF2000-01 ตามโค้ดเดิม ไม่ได้ตรวจสอบเทียบถังจริงใหม่ ระดับที่คำนวณได้อาจติดลบเมื่อปริมาตรต่ำกว่าจุดอ้างอิงของสูตร

## โปรแกรมข้อความเดิม

```powershell
python -X utf8 cal-tf200-new.py
```

เลือก 1 เพื่อคำนวณ และ 2 เพื่อออก โปรแกรมข้อความเดิมยังคงใช้งานได้

## ทดสอบ

```powershell
python -X utf8 -m unittest discover -s tests -v
```

ทดสอบการบวก Load out, สูตรคาลิเบรต, ค่าศูนย์, ข้อมูลผิดรูปแบบ/เกินขอบเขต และปุ่ม/สถานะหน้าต่าง ต้องมีเดสก์ท็อปที่เปิดใช้งานได้สำหรับการทดสอบ GUI
